# PostgreSQL Learning Resources

|---|---|---|
| PostgreSQL Tutorial | https://neon.com/postgresql/tutorial | Structured concepts and syntax reference |
| pgExercises | https://pgexercises.com | Hands-on SQL query practice against a real schema |
| Scrimba SQL | https://scrimba.com/learn-sql-c0et | Interactive SQL course |
| Scrimba Node/Backend | https://scrimba.com/learn-node-c0nj | Wiring Postgres into a real backend project |
